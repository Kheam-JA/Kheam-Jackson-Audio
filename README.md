# Kheam Jackson Audio

A cinematic, Netflix-inspired portfolio website for **Kheam Jackson Audio — FOH & Monitor Engineer**.

## Quick launch with GitHub Pages

1. Upload all project files to the root of your GitHub repository.
2. Open the repository **Settings**.
3. Select **Pages** in the sidebar.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public website address after deployment.

## Editing the website

- Main wording and sections: `index.html`
- Colours, layout and animations: `styles.css`
- Menu and portfolio popups: `script.js`
- Replace the headshot: `assets/kheam-headshot.jpg`

## Adding portfolio media

Create folders such as:

- `assets/photos`
- `assets/videos`

Then replace the starter portfolio cards in `index.html` with your own images, video links and production details.
